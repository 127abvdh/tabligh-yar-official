# تبلیغ‌یار - پلتفرم تبلیغات

پلتفرم تبلیغات آنلاین برای کسب‌وکارهای تهران

## ویژگی‌ها

✅ ثبت‌نام و ورود نمایندگان
✅ دایرکتوری تهران
✅ درخواست تبلیغ با پکیج‌های مختلف
✅ کد معرفی و سیستم کمیشن (۶۵%)
✅ داشبورد شخصی
✅ درگاه پرداخت Zarinpal

## تکنولوژی

- Node.js + Express
- MongoDB
- JWT Authentication
- Bcryptjs

## شروع

```bash
npm install
npm start
```
